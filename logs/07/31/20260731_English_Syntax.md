## 2. 【5文型徹底分解（S, V, O, C, M）】

提示した一文を文法要素ごとに分解し、文の骨組みを明らかにします。

> **The Ministry of Land, Infrastructure, Transport and Tourism (S) / is (V) / set (C) / to initiate procedures for a business suspension against Tokai Kisen (M: 不定詞の形容詞的・副詞的用法関連) / following multiple maritime safety violations (M: 前置詞句).**

* **S (主語)**: *The Ministry of Land, Infrastructure, Transport and Tourism*（国土交通省）
* **V (動詞)**: *is*（〜である）
* **C (補語)**: *set*（準備が整った、状態にある ※be set to do の一部を構成）
* **M (修飾語)**:
* *to initiate procedures for a business suspension against Tokai Kisen*（東海汽船に対する事業停止の手続きを開始するための）
* *following multiple maritime safety violations*（複数の海上安全違反を受けて）



【深掘り解説】:
この文は基本の第2文型（SVC）をベースに構成されています。主語（S）が非常に長いのは、国の省庁名（The Ministry of Land, Infrastructure, Transport and Tourism）が正式名称で記載されているためです。動詞は繋辞（be動詞の *is*）であり、それに続く *set* が主語の状態（〜する方針である）を説明する補語（C）として機能しています。後半の *to initiate...* や *following...* は、それぞれ文全体や直前の表現を修飾するM（修飾語句）として働き、いつ、どのような理由でその方針が取られているのかという背景情報を正確に付け加えています。

## 3. 【英文法・構文の応用解説】

### ① be set to do（〜する方針である、〜する態勢が整っている）

* **公式**: $S + be \text{ set to } + \text{動詞の原形}$
* **解説**: 近い将来に実行されることが確実視されている予定や公式な決定を表します。単なる未来表現（will）よりも客観的な状況証拠や準備完了のニュアンスを含みます。
* **応用例文**: The transport bureau is set to release the official investigation report next week.
（運輸局は来週、公式の調査報告書を発表する方針です。）

### ② 分詞の後置修飾（過去分詞）

* **公式**: $\text{名詞} + \text{過去分詞（} + \text{句）}$
* **解説**: 名詞の後ろから直前の名詞を修飾し、「〜された…」という受動の意味を添えます。ニュース英語では、長くなりがちな修飾関係をすっきりとまとめるために多用されます。
* **応用例文**: The measures taken by the company were insufficient to prevent the accident.
（その会社によって講じられた対策は、事故を防ぐには不十分だった。）

### ③ following 〜（〜の後に、〜を受けて）

* **公式**: $\text{Following } + \text{名詞（句）}$
* **解説**: 前置詞として働き、「〜をきっかけとして」「〜の後に」という時間的・因果関係を示します。ビジネスや報道の文脈で *After* の代わりに好まれるフォーマルな表現です。
* **応用例文**: Following the heavy storm, all ferry services were canceled.
（激しい嵐を受けて、すべてのフェリー便が欠航となった。）

## 4. 【重要語彙・フレーズ】

ニュース読解に欠かせない5つの重要単語を、語源や類義語とともに整理します。

1. **violation** (名詞)
* **意味**: 違反、妨害
* **語源 (Root)**: ラテン語の *violare*（傷つける、乱す）に由来。
* **類義語**: breach, infringement, transgression
* **反対語**: compliance, observance, adherence
* **別の例文**: The airline was penalized for a safety regulation violation.
（その航空会社は安全規則違反で処罰された。）


2. **suspension** (名詞)
* **意味**: 停止、停職、保留
* **語源 (Root)**: ラテン語の *subpendere*（下に吊るす＝宙ぶらりんにする）に由来。
* **類義語**: interruption, halt, pause
* **反対語**: continuation, resumption, extension
* **別の例文**: The committee decided on the suspension of the project.
（委員会はそのプロジェクトの一時停止を決定した。）


3. **crew** (名詞)
* **意味**: 乗組員、乗務員
* **語源 (Root)**: 古英語の *crūned*（積み荷を引き上げる人々）などに由来。
* **類義語**: staff, personnel, team
* **別の例文**: The captain and crew worked together to handle the emergency.
（船長と乗組員が協力して緊急事態に対処した。）


4. **inspection** (名詞)
* **意味**: 検査、視察、監査
* **語源 (Root)**: ラテン語の *inspectio*（中を＋見る）が語源。
* **類義語**: examination, check, audit
* **反対語**: neglect, ignorance
* **別の例文**: Regular inspections are mandatory for all commercial vessels.
（すべての商船にとって定期検査は義務である。）


5. **authorities** (名詞・複数形が一般的)
* **意味**: 当局、関係機関、権威
* **語源 (Root)**: ラテン語の *auctoritas*（影響力、承認）に由来。
* **類義語**: official bodies, government, administration
* **別の例文**: Maritime authorities reported the incident immediately.
（海上保安当局がその事故について直ちに報告した。）

## 5. 【実践演習】

学習した構文や語彙の定着度を確認する3問です。

### 問題 1（書き換え問題）

次の文の「is set to initiate」を、ほぼ同じ意味を持つ「is going to start」に書き換えた際の意味の違いを説明しつつ、以下の空欄を埋めなさい。

> "The ministry ( 1 ) ( 2 ) to take strict measures against the company."

* **解答**: (1) is (2) set
* **解説**: 「〜する方針である・態勢が整っている」という公式なニュアンスを強調するためには *be set to* を用います。

### 問題 2（英作文）

「乗組員は出発前にアルコール検査を受けなければならない。」を英語に訳してください（提示した語彙を使用すること）。

* **解答**: The crew must undergo an alcohol test before departure.
* **解説**: 乗組員を *crew*、アルコール検査を *alcohol test*、受けるを *undergo* や *take* で表現します。

### 問題 3（語彙選択問題）

文脈に最も適する単語を一つ選びなさい。

> "Due to multiple safety ( suspension / violations ), the transport ministry considered heavy penalties."

* **解答**: violations
* **解説**: ペナルティ（処分）が検討される原因となったのは安全に関する「違反（violations）」であるため、文脈上こちらが適切です。
