# Daily English Study Log

英語の文法分解・構文・ニュース解析を蓄積するリポジトリです。
将来的なアプリのグローバル展開、および世界中への情報発信のための「語学のインフラ」を構築します。

## 🎯 プロジェクトの目的
- **グローバル展開:** 開発したサービスを世界中のユーザーに届けるための英語力獲得
- **技術発信:** 海外のエンジニアやランナーとコミュニケーションを取るための武器の習得
- **継続の可視化:** 毎日の積み重ねをGitHubの芝生（草）として記録し、成長を数値化する

## 📝 学習メソッド
- **教材**: 国際ニュースをベースとした独自スクリプト
- **アプローチ**: 
    - **ニュース解析**: 時事英語を通じた語彙力の強化
    - **文法分解**: Basic English 2レベルの構造理解
    - **構文写経**: 基礎構文の徹底的な書き出し
    - **音声出力**: 読み上げ機能（TTS）を活用したリスニング・リズム確認
